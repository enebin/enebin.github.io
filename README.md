# enebin.github.io

enebin의 개인 블로그입니다. GitHub Pages가 자동으로 만들어 주는 Jekyll 정적 사이트입니다.

## 글 추가하기

1. `_posts` 폴더에 `2026-08-08-my-post.md`처럼 `날짜-영문주소.md` 파일을 만듭니다.
2. 기존 글의 위쪽 설정 부분을 복사해 제목, 설명, 분류, 읽는 시간을 바꿉니다.
3. 그 아래에 Markdown으로 글을 씁니다.

홈의 최근 글 목록, RSS, 사이트맵, 검색엔진용 정보는 자동으로 갱신됩니다.

## 소개 바꾸기

`about.html`에서 자기소개 문장을 수정하면 됩니다.

## 검색 노출 준비

- 글마다 `title`과 `description`을 구체적으로 작성합니다.
- 배포 후 Google Search Console에 `https://enebin.github.io/sitemap.xml`을 등록합니다.
- 글 제목과 첫 문단에 사람들이 실제로 찾을 말을 자연스럽게 넣습니다.

## 색과 글꼴 바꾸기

`assets/css/style.css` 위쪽의 색상 값과 글꼴 설정을 수정하면 전체 사이트에 적용됩니다.
